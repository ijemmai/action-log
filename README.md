# Action Log  

A simple app that logs mod actions to a discord channel using webhooks.  

## Actions  

Currently supported actions:  

- member bans  
- member unbans  
![Bans & Unbans Screenshot](https://raw.githubusercontent.com/ijemmai/action-log/main/pictures/bans-unbans.png)  
- post removals  
![Post Removal Screenshot](https://raw.githubusercontent.com/ijemmai/action-log/main/pictures/post-delete.png)  
- comment removals  
![Comment Removal Screenshot](https://raw.githubusercontent.com/ijemmai/action-log/main/pictures/comment-delete.png)  
- mod notes  
![Mod Notes Screenshot](https://raw.githubusercontent.com/ijemmai/action-log/main/pictures/mod-notes.png)  
- removal reasons  
![Removal Reasons Screenshot](https://raw.githubusercontent.com/ijemmai/action-log/main/pictures/removal-reasons.png)  
- Post & Comment Approvals (disabled by default):  
![Approvals Screenshot](https://raw.githubusercontent.com/ijemmai/action-log/main/pictures/approves.png)

## Installation Settings  

Action Log allows you to customize your installation with little to no setup or knowledge required  
![Settings Screenshot](https://raw.githubusercontent.com/ijemmai/action-log/main/pictures/installation-settings.png)
